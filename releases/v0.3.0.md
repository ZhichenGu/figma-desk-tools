## Layout Desk

主页新增 Pinterest 搜索框。输入关键词，按回车打开网站，选好后用截图功能带回左侧参考。也可以在插件内搜索维基共享资源，查看原条目，收藏到当前文件，或移除与恢复版式。

Search Pinterest from the home screen and capture a reference from the results. Browse Wikimedia Commons inside the plugin, open source records and manage layouts saved in the current file.

## ProofDesk

统一中英文界面的产品名。The product name is now ProofDesk in both interface languages.

## 安装 · Installation

下载 LayoutDesk.zip 或 ProofDesk.zip，解压并在 Figma 桌面端导入 manifest.json。Extract your chosen ZIP and import its manifest in Figma Desktop.
