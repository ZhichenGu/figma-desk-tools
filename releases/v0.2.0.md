## 排版台和校样台现已支持中英切换

在 Assets 下载所需插件，解压后从 Figma 桌面端导入对应的 manifest.json。

| 下载 · Download | 功能 · Features |
| --- | --- |
| **LayoutDesk.zip** | 参考图排版、画布取材、文字溢出提醒和继续编辑。 Reference layouts, canvas selection, overflow indicators and reopening saved layouts. |
| **Proofdesk.zip** | 批量调整字体、项目样式基准、英文检查和抠图笔刷。 Bulk typography edits, project style checks, English copy review and cutout brushes. |

Both plugins support Chinese and English. Extract either ZIP and import its manifest in the Figma desktop app. The optional screenshot helper is for Apple Silicon Macs and has a Chinese menu. macOS may request screen recording permission.

[安装与使用 · Installation and examples](https://github.com/ZhichenGu/figma-desk-tools#readme)
