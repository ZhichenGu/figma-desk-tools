- **搜索入口**　主页点「搜索」或按回车会打开「在线找参考图」。Pinterest 是默认来源，切换至维基共享资源或美国国会图书馆时会保留关键词。
- **UI 对齐**　版式名称、搜索框和按钮垂直居中，输入框与按钮等高。
- **插件名称**　排版台 • Layout Desk 和校样台 • ProofDesk 在中英文界面均显示完整名称。

- **Search** — Click Search or press Enter on the home screen to choose a source. Pinterest is selected by default. Switch to Wikimedia Commons or the Library of Congress with the same keyword.
- **Alignment** — The layout name, search field and button are vertically centred. Both controls have the same height.
- **Names** — Both languages display the full names: 排版台 • Layout Desk and 校样台 • ProofDesk.
